# 📐 Математика 5 класс — Единая обучающая платформа

Современная интерактивная веб-платформа для 5 класса с тренажёрами, электронным черновиком в клетку, классной и домашней работой, адаптированная под **смартфоны**, **ПК** и школьные **интерактивные смарт-доски (Smart Board)**.

---

## 🚀 Как включить бесплатный хостинг (GitHub Pages)

Сайт полностью статичен (чистый HTML5, CSS3, JavaScript) и не требует серверов или баз данных.

1. Зайдите в ваш репозиторий на **GitHub**.
2. Откройте **Settings** (Настройки) -> вкладка **Pages** в левом меню.
3. В разделе **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `master` (или `main`), папка `/ (root)`
4. Нажмите **Save**.
5. Через 1-2 минуты ваш сайт будет доступен по бесплатному постоянному адресу:  
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## 🎯 Возможности платформы

1. **Единый каталог уроков:**
   - Быстрый выбор темы из списка или через поиск.
   - Возможность добавлять неограниченное количество новых тем.

2. **Три режима в каждой теме:**
   - 🎯 **Интерактивный тренажёр:** вопросы с 4 вариантами ответов, круговой SVG-шкалой точности, звуковыми эффектами успеха и черновиком в клеточку.
   - 🏫 **Классная работа:** список заданий с мгновенной самопроверкой, подсчётом правильных ответов и похвалой.
   - 🏠 **Домашнее задание:** блок примеров для закрепления материала.

3. **Электронный черновик в клетку:**
   - Поддерживает рисование пальцем, стилусом на смарт-доске и мышью на ПК.
   - Инструменты: Ручка, Полупрозрачный маркер, Ластик, Стереть всё.
   - Сглаживание линий без изломов.

4. **Адаптация под все устройства:**
   - **Смартфоны:** крупные кнопки, отсутствие случайных зумов, поддержка мобильной клавиатуры.
   - **ПК:** мгновенная проверка и переход к следующему полю по клавише `Enter`.
   - **Смарт-доски:** крупный контрастный шрифт, режим «Во весь экран» (кнопка ⛶ в шапке).

## 📁 Как добавить новую тему

### Способ 1. Загрузка через сайт (Мгновенно)
1. Откройте сайт и нажмите кнопку **«📚 Темы -> + Добавить»** (или просто перетащите файл темы мышкой в окно браузера).
2. Выберите файл темы `.json`.
3. Тема мгновенно появится в каталоге и сохранится в памяти устройства!

### Способ 2. Добавление в репозиторий (Для всех учеников сразу)
1. Сохраните новый файл темы в папку `topics/` (например, `topics/equations.json`).
2. Добавьте тему в список `topics/topics.json`.
3. Сделайте `git commit` и `git push` — GitHub Pages автоматически обновит сайт для всех учеников.
